# Pure JS Dynamic Web Page 🚀

A front-end challenge project demonstrating the power of pure Vanilla JavaScript. The entire document structure (HTML), visual styles (CSS), responsive layouts, and interactive events are generated and rendered 100% dynamically via JS DOM manipulation.

---

## ✨ Features

* **Zero HTML/CSS Boilerplate:** Built from a completely blank HTML file; every element is created via `document.createElement()`.
* **CSS-in-JS (Vanilla):** All layouts, typography, spacing, and styles are applied dynamically through JavaScript's `element.style`.
* **Smart Responsive Layout:** Utilizes CSS Grid (`repeat(auto-fit, minmax(...))`) directly inside JS to adapt seamlessly across desktop, tablet, and mobile views.
* **Interactive Hover States:** Custom dynamic hover effects implemented using JavaScript mouse events (`onmouseover` / `onmouseout`).
* **Dynamic Content Rendering:** Product grid items are generated, numbered, and structured programmatically via iterative loops.

---

## 🛠️ Built With

* **Vanilla JavaScript (ES6+)**
* **DOM API** (`createElement`, `appendChild`, `style`, `setAttribute`)
* **Modern CSS concepts** (CSS Grid, Flexbox) injected via JS
